THE BASICS

CSS Grid, made simple

A quick guide to the layout properties behind your generated code.

01

What is CSS Grid?

CSS Grid is a two-dimensional layout system for arranging content in rows and columns at the same time.

.layout {
  display: grid;
}
02

Grid Columns & Rows

Define explicit tracks with grid-template-columns and grid-template-rows. The repeat() function keeps equal tracks concise.

.layout {
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, 1fr);
}
03

Gap

Use gap for both directions, or set column-gap and row-gap independently to tune the space between tracks. 

.layout {
  column-gap: 16px;
  row-gap: 16px;
}
04

Alignment

Items align inside their cells; content alignment positions the tracks within the grid container.

.layout {
  justify-items: center;
  align-content: start;
}
05

CSS Grid vs Flexbox

Grid is ideal for two-dimensional page and card layouts. Flexbox arranges items along one primary axis, making it a natural fit for toolbars, menus, and compact component groups.

.page-layout {
  display: grid;
  grid-template-columns: 16rem 1fr;
}
