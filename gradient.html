THE BASICS

A guide to CSS gradients

Explore gradient types, directions, and the color stops that define them.

01

What is CSS Gradient?

A CSS gradient is an image generated by the browser, blending two or more colors without an image file.

background: linear-gradient(
  90deg, #2563EB, #9333EA
);
02

Linear Gradient

Colors transition along a straight line. The angle or direction controls where the color flow travels.

linear-gradient(
  to right, #2563EB, #9333EA
)
03

Radial Gradient

Colors radiate from a starting point outward in a circle or ellipse.

radial-gradient(
  circle, #2563EB, #9333EA
)
04

Conic Gradient

Color stops rotate around a center point, making pie-chart and color-wheel effects possible.

conic-gradient(
  from 0deg, #2563EB, #9333EA
)
05

Color Stops

A stop pairs a color with an optional position. Stops may share positions to create a hard transition.

linear-gradient(
  90deg, #2563EB 0%,
  #9333EA 100%
)
06

Gradient Direction

Linear-gradient angles start at 0° pointing up and increase clockwise. Direction keywords describe the destination edge.

linear-gradient(
  135deg, #2563EB, #9333EA
)
07

Multiple Color Stops

Add as many colors as needed to create bands or smooth transitions. The CSS order follows each stop’s position, including when positions match.

linear-gradient(
  90deg, #2563EB 0%,
  #06B6D4 50%, #9333EA 100%
)
