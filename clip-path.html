THE BASICS

A guide to CSS clip-path

Learn the shape functions and coordinates behind CSS clipping.

01

What is CSS Clip-path?

clip-path defines a visible region for an element, clipping away the pixels outside the selected shape.

.shape { clip-path: circle(50%); }
02

Circle & Ellipse

Circle and ellipse define a rounded clipping region with a configurable center point.

clip-path: circle(50% at 50% 50%);
clip-path: ellipse(50% 40% at center);
03

Inset

Inset clips a rectangular region from each edge and optionally rounds its corners.

clip-path: inset(10% 12% round 8px);
04

Polygon

Polygon joins three or more points, each described by x and y coordinates.

clip-path: polygon(
  50% 0%, 100% 100%, 0% 100%
);
05

Clip-path Coordinates

Percentage polygon coordinates are relative to the element's reference box and scale with its dimensions.

polygon(0 0, 100% 0,
  50% 100%)
06

Clip-path vs Border Radius

Border-radius rounds box corners. clip-path supports arbitrary shapes but does not change the element's layout box.

border-radius: 20px;
clip-path: polygon(...);
07

Creative Use Cases

Use clip-path for image masks, angled cards, hero illustrations, badges, and decorative elements while retaining normal document flow.

.hero-art img {
  clip-path: polygon(0 0, 100% 8%,
    92% 100%, 8% 92%);
}
