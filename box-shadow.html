    THE BASICS

    A guide to box-shadow

    Learn how each value shapes the appearance of a CSS shadow.

    01

    What is CSS Box Shadow?

    The box-shadow property draws one or more shadows around an element’s frame without changing its layout size.

    .card {
  box-shadow: 0 8px 24px
    rgba(0, 0, 0, .15);
}
    02

    Horizontal & Vertical Offset

    The first value moves a shadow left or right; the second moves it up or down.

    .card {
  box-shadow: 8px 12px
    24px rgba(0, 0, 0, .15);
}
    03

    Blur & Spread

    Blur softens the edge. Spread expands or contracts the shadow before blur is applied.

    .card {
  box-shadow: 0 8px 24px 4px
    rgba(0, 0, 0, .15);
}
    04

    Shadow Color & Opacity

    Use a color with transparency to create shadows that blend naturally with the surface.

    .card {
  box-shadow: 0 8px 24px
    rgba(37, 99, 235, .2);
}
    05

    Inset vs Outset

    Outset shadows appear outside the element. The inset keyword draws a shadow inside its edge.

    .field {
  box-shadow: inset 0 2px 5px
    rgba(0, 0, 0, .12);
}
    06

    Multiple Shadows

    Separate shadow layers with commas. Earlier shadows are painted over later ones.

    .card {
  box-shadow: 0 2px 4px #0001,
    0 12px 24px #0002;
}
