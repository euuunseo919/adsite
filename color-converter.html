    COLOR FORMATS

    A guide to CSS color formats

    Choose the notation that makes your colors easiest to read and maintain.

    01

    What is HEX?

    HEX notation encodes red, green, and blue channel values in base 16. Short and widely used in design tools.

    color: #2563EB;
color: #2563EB80; /* with alpha */
    02

    What is RGB?

    RGB defines a color with red, green, and blue channel values from 0 to 255. It maps directly to the display color model.

    color: rgb(37 99 235);
color: rgb(37 99 235 / 50%);
    03

    What is HSL?

    HSL describes hue, saturation, and lightness. Adjusting lightness makes it convenient to create coordinated shades.

    color: hsl(221 83% 53%);
color: hsl(221 83% 53% / .5);
    04

    HEX vs RGB vs HSL

    All three notations represent colors. Use the format that best fits your workflow: HEX for compact values, RGB for channels, or HSL for intuitive adjustments.

    --hex: #2563EB;
--rgb: rgb(37 99 235);
--hsl: hsl(221 83% 53%);
    05

    What is Alpha?

    Alpha represents opacity from 0 (transparent) to 1 (opaque). Alpha can be expressed in modern CSS color syntax or in 4/8-digit HEX.

    background: rgb(37 99 235 / .5);
color: #2563EB80;
    06

    How to Convert Colors

    Each format is converted through the same underlying RGB channels. HEX channels are decoded from base 16; HSL is calculated from normalized RGB values.

    /* Equivalent color values */
#2563EB
rgb(37, 99, 235)
hsl(221, 83%, 53%)
