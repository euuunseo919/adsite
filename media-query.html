THE BASICS

A guide to CSS media queries

Learn how to target viewport ranges and user preferences responsibly.

01

What is a CSS Media Query?

Media queries conditionally apply styles based on media type, viewport dimensions, and user or device capabilities.

@media screen and (min-width: 48rem) {
  .layout { display: grid; }
}
02

Mobile First vs Desktop First

Mobile-first styles establish a base then add larger layouts; desktop-first approaches constrain styles below a maximum width.

@media (min-width: 768px) { }
@media (max-width: 767px) { }
03

Understanding Breakpoints

Choose breakpoints where your content needs a layout change, and test between common device sizes.

@media (min-width: 48rem) {
  .navigation { gap: 1rem; }
}
04

Width vs Height Queries

Width targets the available inline viewport size. Height can help with constrained or short viewports, but should be used sparingly.

@media (max-height: 600px) {
  .hero { min-height: auto; }
}
05

Orientation Queries

Orientation is determined by the viewport's width-to-height relationship, not by a device's name or category.

@media (orientation: landscape) {
  .gallery { grid-auto-flow: column; }
}
06

User Preference Queries

Respect preferences such as dark mode and reduced motion rather than inferring them from screen size.

@media (prefers-reduced-motion: reduce) {
  *, *::before { scroll-behavior: auto; }
}
07

Media Queries vs Container Queries

Media queries respond to viewport or environment features. Container queries adapt a component to its containing block and are often better for reusable components.

.card-list { container-type: inline-size; }
@container (min-width: 500px) {
  .card { grid-template-columns: 1fr 1fr; }
}
