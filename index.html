Get to know your CSS units

Choose the right unit for accessible, flexible layouts.

Pixels (px)

A fixed-size unit representing one CSS pixel. It does not scale with a parent or root font size.

FAQ

Frequently asked questions

Quick answers to common CSS unit questions.

REM is relative to the root (html) font size, while EM is relative to the computed font size of its parent element. REM is predictable across a page; EM is useful for sizing within a component.

Divide the pixel value by the root font size. For example, with a 16px root size, 24px ÷ 16 = 1.5rem.

No. 1rem equals the root font size. Browsers commonly default to 16px, but users or stylesheets can change that value.

Use REM for typography, spacing, and layout values that should scale with a user's root font-size preference. PX can still be useful for small details such as a thin border.
