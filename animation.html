THE MOTION BASICS

A guide to CSS animation

Understand the timing and keyframe properties behind polished motion.

01

What is CSS Animation?

CSS animations change property values over time using named keyframes and timing settings.

.notice { animation: appear 300ms ease-out; }
02

How @keyframes Works

Keyframes describe intermediate styles using percentages or from/to at the start and end of a cycle.

@keyframes appear {
  from { opacity: 0; }
  to { opacity: 1; }
}
03

Duration & Delay

Duration sets one cycle's length; delay controls how long it waits before the first cycle begins.

animation-duration: 600ms;
animation-delay: 120ms;
04

Timing Functions

Easing controls the rate of change. Cubic Bézier curves customize it, while steps() creates discrete jumps.

animation-timing-function:
  cubic-bezier(.2, .8, .2, 1);
05

Iteration & Direction

Repeat a finite number of cycles or infinitely, and choose whether alternate cycles reverse.

animation-iteration-count: 3;
animation-direction: alternate;
06

Fill Mode

Fill mode determines whether keyframe styles apply before the first cycle or after the last.

animation-fill-mode: both;
07

Animation vs Transition

Transitions usually connect two states after a trigger; animations can define multiple stages and run automatically.

transition: opacity 200ms ease;
animation: appear 500ms ease;
08

Performance Tips

Prefer transform and opacity where possible. They often avoid layout work; keep motion purposeful and honor reduced-motion preferences.

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: .01ms; }
}
