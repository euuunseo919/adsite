THE BASICS

How to use CSS clamp()

Create fluid values without writing a stack of media queries.

01

What is CSS clamp()?

clamp() sets a preferred value between a minimum and maximum. The browser keeps the result within those limits.

02

How does CSS clamp() work?

The middle value scales with the viewport. The first value is the lower bound, and the last value is the upper bound.

03

When should you use CSS clamp()?

Use it for fluid typography, spacing, and layout sizes that should grow smoothly without abrupt breakpoint changes.

A QUICK EXAMPLE

Let a heading scale naturally across screen sizes.

h1 {
  font-size: clamp(2rem, 4vw, 4rem);
}
