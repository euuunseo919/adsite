THE BASICS

A guide to Flexbox

Understand the properties behind your responsive layout.

TWO AXES, ONE DIMENSION

Main axis vs cross axis

The main axis follows flex-direction. The cross axis runs perpendicular to it. Justify content distributes items along the main axis; align items positions them across the cross axis.

MAIN AXIS →
01

What is CSS Flexbox?

Flexbox is a one-dimensional layout model that distributes and aligns items along a row or column.

.toolbar {
  display: flex;
}
02

Flex Direction

Choose the main axis and item flow with row, row-reverse, column, or column-reverse.

.stack {
  flex-direction: column;
}
03

Justify Content

Distribute free space between items along the main axis.

.toolbar {
  justify-content: space-between;
}
04

Align Items

Align items across the cross axis within each flex line.

.toolbar {
  align-items: center;
}
05

Flex Wrap

Allow items to move onto additional flex lines when they no longer fit.

.cards {
  flex-wrap: wrap;
  gap: 16px;
}
06

Grow, Shrink & Basis

Control how an item grows, shrinks, and determines its initial main size.

.item {
  flex: 1 1 200px;
}
07

Flexbox vs CSS Grid

Flexbox is best when content flows along one axis. CSS Grid coordinates rows and columns together, making it a better fit for two-dimensional page layouts.

.page {
  display: grid;
  grid-template-columns: 16rem 1fr;
}
FAQ

Frequently asked questions

Quick answers to common Flexbox questions.

Flexbox arranges and aligns items along a row or column. It is particularly useful for navigation, toolbars, component layouts, and other one-dimensional patterns.

Justify content distributes items along the main axis. Align items positions items along the cross axis inside each flex line.

Set the parent to display: flex, then use justify-content: center and align-items: center to center an item along both axes.

Flex grow distributes positive free space to items. Flex shrink determines how items give up space when the flex line is too small.

Use Flexbox for one-dimensional layouts where content flows along one axis. Choose Grid when you need to coordinate rows and columns across a two-dimensional layout.

Flex wrap allows items that do not fit on one line to continue onto another. Wrap-reverse reverses the cross-axis direction of those lines.

Yes. Combine wrapping, flexible basis values, and gaps to adapt to available space. Media queries can add further changes when the layout needs a breakpoint.
